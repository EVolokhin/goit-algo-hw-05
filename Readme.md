## 1. Аналіз та типові результати експерименту

На основі стандартної поведінки алгоритмів на реальних природно-мовних текстах (наприклад, українською або англійською мовами), результати вимірювань зазвичай демонструють наступну динаміку:

### Підсумок часу виконання (типова таблиця)

| Текст / Підрядок     | Боєра-Мура | Кнута-Морріса-Пратта (KMP) | Рабіна-Карпа   | Найшвидший алгоритм |
| ---                  | ---        | ---                        | ---            | ---                 |
| Стаття 1 (існуючий)  | Найшвидший | Середній                   | Найповільніший | Боєра-Мура          |
| Стаття 1 (вигаданий) | Найшвидший | Середній                   | Найповільніший | Боєра-Мура          |
| Стаття 2 (існуючий)  | Найшвидший | Середній                   | Найповільніший | Боєра-Мура          |
| Стаття 2 (вигаданий) | Найшвидший | Середній                   | Найповільніший | Боєра-Мура          |

> **Примітка:** Якщо існуючий підрядок знаходиться на самому початку тексту, усі три алгоритми показують приблизно однаковий та дуже малий час. Проте при пошуку вигаданого підрядка (коли треба перевірити весь текст) або підрядка у кінці тексту різниця стає очевидною.

## 2. Висновки

### Для Статті 1

- Найшвидшим є алгоритм **Боєра-Мура**. Завдяки механізму зсувів справа наліво він здатний пропускати значні фрагменти тексту, не перевіряючи кожен символ.
- Алгоритм **KMP** демонструє стабільний результат із часом O(N+M), проте перевіряє більше символів у тексті, ніж Боєра-Мура.
- Алгоритм **Рабіна-Карпа** виявився найповільнішим через додаткові обчислення хеш-функцій для кожного вікна.

### Для Статті 2

- Найшвидшим також є алгоритм **Боєра-Мура** як для існуючого, так і для вигаданого підрядка.
- Співвідношення ефективності між трьома алгоритмами залишається аналогічним Статті 1.

### Загальний висновок

- Алгоритм **Боєра-Мура** є найефективнішим загалом для пошуку підрядків у звичайних текстах. Він працює найшвидше за рахунок підходу "порівняння з кінця підрядка" та великих зсувів.
- **Кнута-Морріса-Пратта (KMP)** чудово підходить для випадків, коли у підрядка або алфавіту висока повторюваність (наприклад, ДНК-послідовності або бінарний код), але на природних мовах він поступається Боєра-Мура.
- **Рабіна-Карпа** більше підходить для задач пошуку декількох підрядків одночасно, а для пошуку одного підрядка в чистому вигляді поступається у швидкості через витрати на хешування.
